# CoreGuard Enterprise

**Лёгкая система мониторинга состояния накопителей и температурного режима для Windows (Open Source / GPLv3)**

CoreGuard Enterprise — автономный программный комплекс на Go для системных администраторов. Считывает SMART-диагностику NVMe и SATA накопителей напрямую через системные вызовы ядра Windows (DeviceIoControl), отслеживает температуры и объединяет все ПК в единой консоли.

## Возможности
- **Нативный движок SMART (Windows IOCTL):** Прямой опрос контроллеров NVMe и SATA без внешних утилит (smartctl.exe не требуется).
- **Точная оценка ресурса SSD и HDD:** Контроль процента износа, резервных блоков, температуры, наработки в часах, объёма записи и полная таблица атрибутов SMART в локальном дашборде.
- **Тихий агент в системном трее:** Работает без консольных окон (-H=windowsgui) с графиками температур в реальном времени.
- **CoreGuard Central Hub:** Единый веб-интерфейс администратора (:9090) с журналом тревог и уведомлениями в Telegram.

## Сборка
```powershell
go build -ldflags="-H=windowsgui" -o CoreGuard.exe .
go build -ldflags="-H=windowsgui" -o coreguard_hub.exe ./cmd/hub
.\build.ps1
```
