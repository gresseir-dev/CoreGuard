# CoreGuard Enterprise (v2.3.31) — Обзор решения

**CoreGuard Enterprise** — компактное решение на базе **Go** для непрерывного мониторинга накопителей (**S.M.A.R.T.**), температур и дискового пространства на Windows-серверах и рабочих станциях, а также централизованного администрирования через **CoreGuard Central Hub**.

## Что входит в систему
* **Агент CoreGuard (CoreGuard.exe):** фоновый сбор метрик S.M.A.R.T., температур ЦП/платы/накопителей и свободного места на системном диске, локальный веб-интерфейс и API на порту 48123 (HTTP Basic Auth).
* **Центральный Хаб (coreguard_hub.exe, порт 9090):** единая панель состояния парка (HEALTHY / WARNING / CRITICAL), журнал событий, Telegram-уведомления, авто-инициализация локального узла (local-pc) и брендирование организации/MSP.
* **Единое OTA-обновление через GitHub Releases:** загрузка актуального релиза с GitHub в один клик — обновление пакета агента в eleases/ (с проверкой SHA-256), самообновление coreguard_hub.exe с перезапуском службы и раскатка обновлений на агенты по сети.
* **Гибкая установка (GPLv3):** установка агента, Хаба или обоих компонентов через инсталлятор Windows (с отключённой по умолчанию опцией ярлыка на рабочем столе).
