# CoreGuard Enterprise: Мониторинг и наблюдаемость без лишней сложности

## 1. Концепция и позиционирование
CoreGuard Enterprise — это распределённая система мониторинга инфраструктуры, серверов и рабочих станций Windows, созданная для команд, которым нужен мгновенный контроль над парком машин без многонедельного внедрения.

В то время как классические платформы мониторинга (Zabbix, OpenPegasus / WBEM-системы) требуют выделенных баз данных (PostgreSQL/MySQL), сложных конфигураторов с сотнями параметров, компиляции MOF-схем и долгой настройки шаблонов, CoreGuard разворачивается **в несколько кликов** и готов к работе «из коробки».

---

## 2. Ключевые преимущества

### ⚡ Развёртывание за 2 минуты (Zero-Dependency)
- Установка через единый графический инсталлятор в `Program Files` без сторонних зависимостей, СУБД или внешних интерпретаторов (Python, PHP, Java).
- Автоматическая регистрация системной службы Windows (`CoreGuardHub`) и ярлыков управления.
- Автономный портативный агент с объёмом потребления оперативной памяти менее 15 МБ.

### 🎛 Централизованное управление против громоздких решений
- **Вся настройка — в едином окне:** добавление узлов, изменение интервалов опроса и порогов телеметрии осуществляются прямо через центральную веб-панель (Enterprise NOC Dashboard на порту `9090`).
- Никаких ручных манипуляций со сложными XML/MOF схемами OpenPegasus или многоуровневыми правилами обнаружения Zabbix: узел подключается указанием IP-адреса и порта.

### 🔔 Мгновенные Telegram-оповещения и оперативный контроль
- Встроенная интеграция с Telegram Bot API: критические инциденты (перегрузка CPU/RAM, дефицит места на дисках, потеря сетевой связности) моментально отправляются дежурному администратору в чат.
- Поддержка форматированных сообщений с указанием имени узла, метрики и точного времени инцидента.

### 📋 Журнал событий и двухфакторное подтверждение (ACK)
- Встроенный журнал инцидентов с фиксацией времени возникновения аварии.
- Механизм квитирования (Acknowledge / ACK): возможность подтвердить обработку тревоги прямо из интерфейса NOC, предотвращая дублирование реакции дежурных специалистов.

### 🔄 Гибридная архитектура для непрерывного продакшена и отладки
- Единый бинарник `coreguard_hub.exe` автоматически определяет контекст запуска:
  - **Режим службы Windows (SCM):** бесперебойная фоновая работа с защитой от сбоев.
  - **Консольный режим:** интерактивный запуск для локальной диагностики и проверки конфигураций в один клик.

## 3. Сравнительный анализ с аналогами

| Параметр | CoreGuard Enterprise | Zabbix | OpenPegasus (CIM/WBEM) |
| :--- | :--- | :--- | :--- |
| **Время развёртывания** | **Менее 2 минут** | От 2–4 часов | Дни (компиляция MOF) |
| **Зависимости** | **Нет (Single Exe)** | СУБД, Веб-сервер, PHP | Библиотеки CIMOM, компиляторы |
| **Управление узлами** | **Интуитивная панель NOC** | Сложные шаблоны и макросы | Запросы WQL/CIM-XML |
| **Оповещения в Telegram** | **Встроены в ядро** | Через скрипты и Webhook | Требуют внешних шлюзов |
| **Нагрузка на клиент** | **< 15 МБ RAM** | 30–70 МБ RAM | Зависит от CIM-провайдеров |

---

## 4. Системные требования и архитектура
- **Поддерживаемые ОС:** Windows 10, Windows 11, Windows Server 2016 / 2019 / 2022 / 2025 (x64).
- **Сетевые интерфейсы:** Порт `48123` (локальный агент телеметрии), порт `9090` (Enterprise Hub Dashboard).
- **Формат хранения настроек:** Человекочитаемые структурированные файлы JSON (`hub_config.json`, `nodes.json`), поддерживающие прямое версионирование и резервное копирование.
