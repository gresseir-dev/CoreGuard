# CoreGuard Enterprise — Optional Utilities ('utils/')

В этом каталоге размещаются опциональные консольные и вспомогательные утилиты, не входящие в базовый инсталлятор:
- **coreguard_scanner.exe** — сетевой сканер подсети для поиска узлов и активных агентов CoreGuard (порт 48123).
- **coreguard_msp_setup.exe** — генератор корпоративного профиля брендинга ('msp_profile.json') для автоматического развёртывания.

Готовые скомпилированные '.exe' файлы утилит доступны для скачивания в разделе [Releases](https://github.com/gresseir-dev/CoreGuard/releases).
