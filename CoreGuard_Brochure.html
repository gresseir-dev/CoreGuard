CoreGuard

Комплексный мониторинг и защита ИТ-инфраструктуры
Enterprise Ready
CoreGuard — автономное высокопроизводительное решение для мониторинга аппаратного состояния серверов и парка ПК. Предотвращает отказ накопителей, перегрев компонентов и переполнение системных дисков до наступления сбоя.

Архитектура решения

1. Локальный агент (CoreGuard.exe)

Фоновый процесс без сторонних runtime-зависимостей. Опрашивает контроллеры SATA/NVMe, снимает температуру CPU/платы, проверяет диск C: и поднимает локальный UI (:8080).

2. Центральный хаб (coreguard_hub.exe)

Единый NOC-экран на порту 9090 для системных администраторов. Автоматически опрашивает агентов по сети, группирует узлы и агрегирует здоровье парка.

Ключевой функционал

Глубокий анализ SMART (NVMe / SATA)

Прямой опрос контроллеров: счетчики износа (Wear/Spare), сбойные сектора (05/C5/C6), ошибки носителя и статус деградации в реальном времени.

Защита от перегрева и переполнения

Пороговые предупреждения по температуре ЦП и системной платы, а также учет свободного места на системном диске C:.

Встроенный GUI-конфигуратор хаба

Добавление, редактирование хостов и распределение по группам (Бухгалтерия, Склад, Серверы) прямо через браузер без ручной правки JSON.

Защищенный REST API & Безопасность

Сетевой интерфейс передачи телеметрии на порту 48123 с авторизацией (Basic Auth), фильтрацией IP-адресов и лицензированием Ed25519.
