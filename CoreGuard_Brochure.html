CoreGuard Enterprise

Аппаратный мониторинг накопителей и централизованный контроль парка ПК
Release v2.1.4
Архитектура: Windows x64
CoreGuard — программный комплекс для непрерывного контроля физического состояния SSD и HDD накопителей, системных температур и аппаратной стабильности компьютеров. Построен на прямом обращении к контроллерам Windows API без громоздких внешних библиотек и ориентирован на корпоративную эксплуатацию.

Ключевые возможности версии v2.1.4

⚙ Низкоуровневая телеметрия NVMe & SATA
Прямой опрос накопителей через NVMe IOCTL и чтение сырых атрибутов SMART SATA (WMI/kernel). Мгновенное выявление износа ячеек памяти, переназначенных секторов и деградации интерфейса.
🛡 Автономная служба Windows Service
Центральный сервер CoreGuard Hub функционирует в качестве фоновой системной службы (аккаунт SYSTEM). Не требует активного входа пользователя, автоматически перезапускается и работает без открытых консолей.
🖥 Двойной вид: Сетка карточек и Таблица
Мгновенное переключение интерфейса дашборда: наглядные информативные карточки для экспресс-оценки или компактный табличный список для контроля десятков и сотен рабочих мест. Сохраняется в настройках.
🎯 Разделение «Сервер 24/7» и «Рабочая станция»
Интеллектуальная фильтрация сетевых алертов: круглосуточные сервера строго контролируются на доступность, а рабочие станции сотрудников не засоряют дежурный чат тревогами при штатном выключении ПК.
📲 Оповещения в Telegram с журналом ACK
Мгновенные push-уведомления дежурным администраторам при перегреве ЦП, критическом падении свободного места на диске C: или сбоях дисков. Встроенный веб-журнал с квитированием инцидентов.
🔒 100% On-Premise Безопасность
Вся телеметрия и журналы передаются по локальной сети компании через REST API и хранятся внутри инфраструктуры. Полная автономность без внешних облачных зависимостей.
