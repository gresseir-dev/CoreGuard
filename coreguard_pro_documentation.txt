# CoreGuard PRO

CoreGuard — легковесный автономный инструмент системной телеметрии и превентивной защиты инфраструктуры Windows от аппаратных сбоев. Разработан на Go с использованием прямого WinAPI для обеспечения непрерывного мониторинга накопителей, критических томов и температурного контура.

================================================================================
КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ
================================================================================

- Direct SmartProbe (Низкоуровневый SMART):
  Прямой опрос накопителей через WinAPI IOCTL (NVMe Log Page 0x02 и ATA Pass-Through) 
  в обход зависающего Windows WMI.

- Поддержка специфики вендоров:
  Корректное считывание часов наработки (POH), температур и износа ячеек для 
  накопителей Intel/Solidigm, Samsung, Western Digital, Kingston, Crucial.

- Контроль деградации:
  Отслеживание переназначенных секторов (Reallocated Sectors), нестабильных блоков 
  (Pending Sectors) и критических флагов надежности.

- Защита баз данных (1C / SQL):
  Контроль переполнения системного диска C: с настраиваемыми порогами срабатывания 
  (Warning / Critical).

- Тепловой контур:
  Сплайн-графики динамики температур дисков, процессора и материнской платы с 
  визуальными зонами перегрева.

- Фоновая автономия:
  Работа в системном трее с мгновенными Windows-уведомлениями, потребление ОЗУ < 15 МБ.

- Криптографическое лицензирование:
  Подпись и валидация лицензий (FREE / PRO / ENTERPRISE) на базе Ed25519.

- Автоматизация спасения данных (PRO):
  Фоновый запуск аварийных скриптов бэкапа при фиксации предаварийного состояния дисков.

================================================================================
СБОРКА ИЗ ИСХОДНИКОВ
================================================================================

Требования: Go 1.21+ и ОС Windows.

1. Сборка основного бинарника CoreGuard (без консольного окна):
   go build -ldflags="-H windowsgui -s -w" -o CoreGuard.exe .

2. Сборка графического генератора лицензий:
   go build -ldflags="-H windowsgui -s -w" -o keygen_gui.exe ./cmd/keygen
