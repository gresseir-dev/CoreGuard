                         STORAGEGUARD (RU)
======================================================================
Платформа: Windows 10 / 11 / Windows Server 2016+
Язык:      Go 1.21+
Лицензия:  Коммерческая (gresseir-dev)

ОПИСАНИЕ
----------------------------------------------------------------------
StorageGuard — профессиональная система аппаратного мониторинга дисковой
подсистемы и превентивной защиты данных для Windows. Спроектирована для
защиты критически важных баз данных (1С:Предприятие, MS SQL, PostgreSQL)
от внезапного выхода из строя SSD-накопителей, перегрева и переполнения
дискового пространства.

В отличие от стандартных утилит, StorageGuard не зависит от стандартных
счетчиков WMI/Windows, опрашивая контроллеры напрямую через WinAPI и
протокол NVMe, и обеспечивает мгновенную реакцию при первых признаках
аппаратного сбоя.


КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ
----------------------------------------------------------------------
* Прямой низкоуровневый опрос накопителей: решает проблему возврата
  нулевых значений штатными драйверами Windows (например, для накопителей
  Intel 660p/760p NVMe) путем прямого считывания страницы лога NVMe 0x02.
* Модульная система профилей вендоров (smartprobe): корректное
  декодирование атрибутов для накопителей Intel/Solidigm, Samsung V-NAND,
  Western Digital/SanDisk и стандартных JEDEC NVMe/ATA устройств.
* Реактивный аварийный бэкап: автоматический скрытый запуск скриптов
  резервного копирования баз (через VSS теневые копии) сразу при
  фиксации деградации памяти или перегрева, не дожидаясь ночного расписания.
* Раздельный мониторинг параметров: независимая оценка емкости тома C:
  (круговая диаграмма с настройкой критического порога в %) и температур
  процессора/материнской платы для исключения ложных тревог.
* Интеграция в системный трей Windows: легковесный процесс на чистом WinAPI,
  контроль единичного экземпляра через мьютекс и системные уведомления.
* Локальный и сетевой дашборд: встроенный локальный интерфейс
  (localhost:48123) и защищенный удаленный доступ для администратора с
  Basic-аутентификацией и белым списком IP-адресов.

СБОРКА ИЗ ИСХОДНИКОВ
----------------------------------------------------------------------
Требования:
  - Windows 10 / 11 / Windows Server 2016+
  - Go версии 1.21 или выше
  - Права Администратора (для открытия хэндлов \\.\PhysicalDriveX)

Команда компиляции:
  go build -ldflags="-H windowsgui -s -w" -o StorageGuard.exe main.go smartprobe.go

Запуск в тестовом режиме:
  StorageGuard.exe -test


БЕЗОПАСНОСТЬ
----------------------------------------------------------------------
Программа работает полностью локально. Данные телеметрии и конфигурация
не передаются на внешние серверы, если не активирован централизованный
модуль Enterprise. Проверка лицензионных ключей осуществляется офлайн
с использованием криптографических подписей Ed25519.
