# Changelog — CoreGuard Enterprise

## [2.4.2] — 2026-11-25

### Исправления и улучшения
- **Надёжный самоперезапуск службы Central Hub (/api/github/self-update):** завершение процесса при обновлении переведено на отвязанный от группы процессов службы фоновый сценарий (DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_BREAKAWAY_FROM_JOB), который дожидается остановки старого coreguard_hub.exe и гарантированно запускает службу CoreGuardHub заново.
## [2.4.1] — 2026-11-25

### Новые возможности
- **Мастер профиля обслуживающей компании (coreguard_msp_setup.exe):** утилита (cmd/msp_setup) для однократной настройки реквизитов MSP/сервисной организации (название компании, телефон, Telegram, email) с сохранением в msp_profile.json рядом с дистрибутивом.
- **Автоматический подхват реквизитов MSP при установке:** инсталлятор (installer.iss) автоматически копирует {src}\msp_profile.json в папку установки, а служба CoreGuardHub при запуске применяет данные обслуживающей организации в hub_config.json и рассылает их агентам — при развёртывании у нового клиента остаётся указать только название обслуживаемой организации.
- **Полный набор утилит развёртывания в релизе и {app}\tools:** в комплект поставки и GitHub Releases включены coreguard_scanner.exe (инвентаризация парка ПК) и coreguard_msp_setup.exe (профиль обслуживающей организации).
## [2.4.0] — 2026-11-25

### Новые возможности
- **Автономный сканер парка машин (coreguard_scanner.exe):** консольная утилита инвентаризации для запуска с USB-флешки или общей сетевой папки (cmd/scanner). Автоматически определяет имя компьютера, активного пользователя, основной IPv4-адрес и доступность порта агента 48123, безопасно записывая данные в leet_inventory.json с файловой блокировкой Windows (LockFileEx).
- **Пакетный импорт узлов в Central Hub (POST /api/nodes/import):** во вкладке **«Центр управления → Парк компьютеров (Nodes)»** добавлена кнопка **«📥 Импорт списка ПК (.json)»** для массового добавления и обновления рабочих станций в один клик с немедленным запуском опроса.
- **Интеграция в дистрибутив:** coreguard_scanner.exe включён в сборку инсталлятора ({app}\tools\coreguard_scanner.exe), ярлык меню «Пуск» и вложения релиза на GitHub.

### Исправления и улучшения
- **Надёжный перезапуск агента при обновлении (POST /api/update):** исправлено экранирование аргументов при перезапуске CoreGuard.exe после подмены бинарника — процесс теперь гарантированно поднимается после освобождения coreguard.lock.
- **Полное самообновление из Central Hub:** в /api/github/check добавлены флаги версии агента и Хаба, реализован эндпоинт /api/github/self-update, а для Windows-службы CoreGuardHub настроен автоматический перезапуск через SCM (sc.exe failure).
- **Управление списком узлов без «залипания» дублей:** при сохранении конфигурации в Хабе удалённые узлы корректно очищаются из оперативного кэша состояний hub.states и сразу исчезают с дашборда.
