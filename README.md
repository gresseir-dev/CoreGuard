# CoreGuard Enterprise v2.1.5

Комплексная система мониторинга инфраструктуры и рабочих станций в реальном времени.

## Компоненты системы
1. **CoreGuard Agent (CoreGuard.exe)** — легковесный фоновый агент сбора метрик и телеметрии (порт по умолчанию: `48123`).
2. **CoreGuard Central Hub (coreguard_hub.exe)** — гибридный сервер агрегации данных (Enterprise NOC), работающий как в виде консольной утилиты, так и в качестве службы Windows (порт по умолчанию: `9090`).

## Быстрый старт
- **Консольный режим:** Запустите `coreguard_hub.exe`. Веб-интерфейс доступен по адресу `http://localhost:9090`.
- **Режим службы Windows:** Установите приложение через инсталлятор `CoreGuard_Setup_v2.1.5.exe` с правами администратора. Служба `CoreGuardHub` настроена на автоматический запуск.

## Конфигурационные файлы
- `config.json` — параметры локального агента.
- `hub_config.json` — системные настройки хаба, параметры алертинга и пороги инцидентов.
- `nodes.json` — реестр наблюдаемых узлов.
